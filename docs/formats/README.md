# Formats

The catalog's formats — `plugins/<id>.toml`, `withdrawn.toml`, and the published index — are owned by the angelica repository: [catalog format 1](https://github.com/AngelicaProject/angelica/blob/main/docs/formats/catalog-v1.md). The plugin's own manifest is owned there too: [plugin manifest v1](https://github.com/AngelicaProject/angelica/blob/main/docs/formats/plugin-manifest-v1.md).
