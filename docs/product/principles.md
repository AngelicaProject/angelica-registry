# Catalog principles

1. **Built from source.** Every published plugin is built by the registry's workflow from the source at the tag in its entry. What players run is what the registry built, not a file the author uploaded.
2. **The author agrees.** An entry's tag must have a plugin file signed with the entry's author key, so nobody publishes a plugin in its author's name.
3. **Signed by the catalog.** Published plugins and the index are signed with the release key; Angelica marks such plugins as coming from the catalog.
4. **People review only what reaches beyond the player.** An update that declares nothing more merges by itself, and so does a new plugin that does not act for the player, use the internet, or see other players; anything else, and more permissions, wait for a maintainer.
5. **Withdrawal is possible.** A withdrawn version or plugin is turned off in every installation.
