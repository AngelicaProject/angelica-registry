# Contribute to the Angelica registry

The canonical guidance lives in [`docs/`](./docs/README.md).

- To publish or update a plugin, read the [catalog principles](./docs/product/principles.md) and the [submission flow](./docs/architecture/overview.md).
- To change the registry itself, start with the [contribution workflow](./docs/development/contributing.md).

## Pull requests

Follow the [pull request standards](./docs/development/pull-requests.md). A submission states the plugin version and, for an update, every permission and map entry it adds.

## Security issues

Do not open a public issue for a plugin that abuses its permissions or a way to publish unbuilt code. Report it privately to the maintainers.
