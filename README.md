# Angelica registry

The catalog of plugins for [Angelica](https://github.com/AngelicaProject/angelica). Each plugin is published from a source commit that the registry builds, checks, and signs; the in-game catalog reads the signed index.

## Submitting a plugin

A submission is a pull request that adds or updates `plugins/<id>.toml` with the plugin's repository and commit. See the [documentation](./docs/README.md).
